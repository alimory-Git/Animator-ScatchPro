Quick Start: Your First Animated Sketch

This is a frame-by-frame drawing environment: draw on the canvas, create frames, compare neighbouring drawings with Onion Skin, preview playback, and export the result. The fastest way to learn is to build a tiny 5–8 frame exercise first.

  1. Open the app and choose New Project.
  2. Choose 1920×1080 or a preset; use a smaller canvas for quick tests.
  3. Set paper colour, pencil colour, widths and FPS, then click Create Project.
  4. By default, hold Ctrl and move the mouse over the canvas to draw. If “Draw with left click / pen tablet” is enabled, drawing can work without Ctrl.
  5. Click + New to create the next frame and change the drawing slightly.
  6. Enable Onion Skin to compare the previous drawing.
  7. Press Space to play; save the editable project with Ctrl+S.
Important: creating a new project clears the current frames. Save first.

Understand the Interface

The image below is an annotated schematic of the interface regions derived from the supplied HTML structure; it is not a live screenshot. It identifies the major regions and their intended roles.

Overall layout. Exact panel sizes may vary with the window size and whether panels are collapsed.

  1. Layers sidebar: select and add layers.
  2. Top toolbar: new project, settings, pencil colour, bucket/palette, paper colour, save/load, export, Onion Skin, reset view, fullscreen and shortcuts.
  3. Central canvas: the drawing surface. Zoom and rotation can move the paper away from its default view; Reset View restores the view.
  4. Quick Pen and palette: frequently used brush, eraser, opacity, smoothing and Real Pencil controls; the palette may be collapsed.
  5. Playback bar: playback, quick preview, FPS, Loop and Onion playback.
  6. Frames sidebar: frame range, insert/new/duplicate/clear/delete/move actions and thumbnails.
  7. Help/status area: key-state hints, current frame, Onion status and brush width.

Drawing, Brush and Eraser

Basic drawing

By default, hold Ctrl and move the mouse to draw. Hold Shift while moving to erase. This modifier-key workflow avoids permanently switching tools.

  • Brush width: overall line thickness.
  • Eraser width: size of the erased area; it can differ from the brush width.
  • Minimum %: lower width limit when line width varies.
  • Opacity %: line opacity. Lower values are useful for pale construction sketches.
  • Smoothing: path smoothing; higher values can reduce jitter but soften sharp corners.
  • Sampling: path sampling density. Smaller intervals may capture detail better at a processing cost.
  • Acceleration sensitivity: affects how speed influences width.

Quick Pen controls

Use the Quick Pen sliders for immediate adjustments. The numeric labels show current values. The reset button beside Real Pencil restores that mode’s preset; note your preferred values before resetting.

Real Pencil and Outline

Real Pencil enables a dedicated pencil preset. Outline has three modes: Uniform, Sketch imitation, and Blend. Influence controls the sketch-style effect; Minimum % sets its lower width bound. Use Uniform for consistent strokes, Sketch for a sketchier feel, and Blend for a compromise.

Controlled testing: draw several short lines at different speeds. Change one setting at a time to identify its effect.

Frame Management

Each frame is one image state in the animation. Motion comes from controlled differences between successive frames.

  • + New: creates a new frame.
  • Insert: inserts a frame at the current position/before the current frame; it is not the same as New.
  • Duplicate: copies the current frame so you can make a small change without redrawing everything.
  • Clear Page: clears the current frame’s contents but does not necessarily remove the frame.
  • Delete Frame: removes the frame from the sequence.
  • Up / Down: changes the frame’s order in the sequence.

Thumbnails and selection

Click a thumbnail to select that frame. Arrow keys navigate the sequence. Check the frame number and thumbnail before clearing, deleting or moving a frame.

Preview range

The From and To fields above the frame list define the range used by quick preview. Frame numbering starts at 1. The app normalizes reversed endpoints, but entering the intended range clearly is best.

Do not confuse: Clear Page keeps the frame but clears its drawing; Delete Frame removes the frame from the sequence.

Onion Skin: Compare Neighbouring Frames

Onion Skin overlays nearby frames translucently on the current frame. It helps you judge continuity, spacing, arcs and unintended jumps.

  1. Click Onion in the top toolbar.
  2. Set the number of previous frames in Settings; the source default is 3.
  3. Choose a colour for previous frames (default red).
  4. Optionally set future frames above zero and choose the second colour (default blue).
  5. Adjust opacity so the current frame remains clear.
  6. Step through frames and compare the motion path.

Fade: “Faint to strong” helps distinguish temporal distance; “Equal” uses similar intensity for each frame. “Onion during playback” allows Onion while playing. The separate Onion Play button is also available on the playback bar.

If the canvas looks cluttered: reduce frame counts or opacity. Set future frames to zero if they distract you.

Layers

The left sidebar is labelled “Layers / Columns”. Layers help separate drawing components such as rough sketch, cleanup, background and details.

  • + Column: adds a layer.
  • Select a layer: determines which layer receives the current drawing/edit.
  • Visibility: temporarily hides a layer to compare the composite.
  • Opacity and blur: layer data is supported by the project structure; the exact visible controls depend on the current layer-panel UI.
  • Per-layer Onion: the program logic supports Onion control for individual layers.

Default shortcuts: Shift+L new layer, PageUp/PageDown previous/next layer, V toggle active-layer visibility, and G toggle Onion for the active layer.

Suggested workflow: name layers by role. Avoid keeping every element on one layer if you expect to edit or hide elements independently.

Playback and Quick Preview

Normal playback

Click Play or press Space to show the frame sequence at the selected FPS. FPS means frames per second; 12 FPS displays 12 frames each second. Higher FPS does not automatically improve animation—spacing and timing matter.

  • Loop: repeats the sequence when it reaches the end.
  • Onion Play: controls Onion display during playback.
  • FPS: use the playback-bar field; Shift+Up/Down also changes it.

Quick Preview (Enter)

Quick Preview prepares the frames first, then plays them to reduce rendering overhead during playback. Options include Auto/25%/50%/75%/100% scale, Loop/Once/Ping-pong, HUD and saving the preview FPS back to the app.

Follow the on-screen preview hint: Space pauses/resumes, Left/Right steps frames, Up/Down changes speed, L changes playback mode, H toggles information, F toggles fullscreen, and Enter or Esc exits.

If preview is slow: try 25% or 50%. If the image is too soft, try 75% or 100%. Limit the preview range when appropriate.

Pencil, Paper and Palette

Pencil colour and paper colour are separate. Pencil colour applies to new strokes; paper colour controls the canvas background. Use the colour pickers beside Pencil and Paper in the top toolbar.

Palette

The Bucket button opens the palette/fill tools. The palette on the right may be collapsed; use its vertical colour handle to open it. “+ Colour” adds a custom colour and the reset button restores the default palette. M toggles floating tools near the pointer; the pin switches between floating and fixed placement.

Palette management

The palette manager includes add/delete colour, eyedropper sampling from the canvas, copy to header, replace a colour across all frames, erase a colour across all frames, gap-closing tolerance, fill/replace colour, clear colour, and JSON import/export.

  • Tolerance: helps fill regions with small line gaps. Too much tolerance can leak across boundaries.
  • Global replacement: affects all frames; inspect the result carefully.
  • Eyedropper: sample an existing canvas colour instead of guessing its value.
Operations labelled “all frames” have broad effects. Save a separate JSON copy before global replacement or erase operations.

Save, Load and Project Files

Save JSON stores an editable project; Load opens a JSON project. This is different from video export: JSON is for continued editing, MP4/WebM for playback, and PNG/JPG sequences for frame-by-frame images.

  1. After important changes, press Ctrl+S or click Save JSON.
  2. Use a meaningful filename, such as `scene_01_v02.json`.
  3. To reopen, choose Load or Ctrl+O and select the JSON file.
  4. After loading, verify frame count, active layer and paper colour.

The source stores layers and each layer’s frames, and also recognises a legacy `frames` array format. This does not guarantee compatibility with every historical or manually edited file.

Settings backup

Settings → General has “Export settings + shortcuts” and “Import from file”. This is a separate JSON backup for preferences and shortcuts, not the project file. Factory Reset restores settings and shortcuts and reloads the page; the app warns that the open project is not saved.

Export Video and Image Sequences

Click Export to open the export dialog. Choose format, range, size, FPS, quality and destination before starting.

Formats

  • MP4 (H.264): broadly compatible video. The source includes an internal H.264 encoder.
  • WebM (VP9): video; export may use WebCodecs or live recording depending on browser capabilities.
  • JPG sequence: one image per frame with adjustable quality; paper colour is retained.
  • PNG sequence: lossless images; transparent background can export the drawing without paper colour.

Export options

  • Frame range: From/To; All, Playback Range and Current Frame buttons speed selection.
  • Scale: 100%, 75%, 50% or 25% of original dimensions.
  • FPS: video playback rate and final duration.
  • Repeat: number of times the sequence repeats in the video.
  • Quality: quality/size trade-off; PNG is lossless and disables this control.
  • Frame number: prints a frame number in the corner.
  • Transparent background: PNG only.
  • Filename: output basename.
  • Save to: one ZIP, direct folder or separate files.

Approximate video duration = frame count × repeat count ÷ FPS. For example, 24 frames repeated twice at 12 FPS produce about 4 seconds.

Tip: export a small range at 25% first. After checking timing and framing, make the final export at the desired size and quality.

Complete Settings Reference

The Settings dialog has six tabs. Review changes and click Save; Close exits the dialog. Some values are also available in Quick Pen.

1. Pen

  • Maximum width: brush width ceiling.
  • Eraser width: eraser size.
  • Minimum %: lower width limit.
  • Opacity: stroke opacity.
  • Sampling: path sampling amount; compare detail and smoothness after small changes.
  • Smoothing: path smoothing.
  • Acceleration sensitivity: speed influence on width.

2. Paper & Onion

  • Pencil and paper colours.
  • Previous-frame count and colour.
  • Future-frame count and second colour; zero disables future frames.
  • Onion opacity and fade mode.
  • Onion during playback.

3. Playback & Preview

  • Playback FPS (1–60) and Loop.
  • Preview scale: Auto, 25%, 50%, 75%, 100%.
  • Playback mode: Loop, Once or Ping-pong.
  • HUD: frame number, measured FPS and dropped frames; H also toggles it in preview.
  • Sync preview FPS back to the main app when closing preview.

4. Export

  • Default format, scale, quality, repeat count and frame-number overlay.
  • Default image-sequence destination.
  • Default filename.

5. View & Mouse

  • Zoom step: zoom increment per shortcut.
  • Rotation step: angle increment for comma and period keys.
  • Angle snap: Free or snap to 1°, 5°, 15° or 45° multiples.
  • Draw with left click / pen tablet: enables drawing without Ctrl.
  • Fullscreen frame number: show the frame badge in fullscreen.
  • Display duration: how long the badge remains visible, in milliseconds.

6. General

  • Enable/disable bottom smart hint and tip popups.
  • Open the first-run guide and shortcut help (F1).
  • Undo/Redo history levels (5–100; default 40).
  • Export/import settings and shortcuts, factory reset, and reset settings.
Two different resets: Reset Settings and Factory Reset are not the same. Factory Reset clears preferences and shortcuts and reloads the page; the open project is not saved.

Three Step-by-Step Practice Projects

Exercise 1: An 8-frame bouncing ball

  1. Create a 1920×1080 project at 12 FPS.
  2. Draw a ball near the top of the canvas on frame 1.
  3. Duplicate the frame and move the ball slightly down.
  4. Enable Onion Skin and compare spacing.
  5. Use tighter spacing near the ground contact and wider spacing on the way up.
  6. Play the sequence and refine the spacing.
  7. Export a short MP4.

Exercise 2: A separate arm layer

  1. Create one layer for the body and another for the arm.
  2. Keep the body still and change only the arm between frames.
  3. Use V to hide/show a layer to inspect the composite.
  4. Save JSON, then export.

Exercise 3: Transparent output for compositing

  1. Choose PNG sequence.
  2. Enable transparent background.
  3. Export a short test range.
  4. Open one PNG in an image viewer and verify transparency.

Troubleshooting and Documentation Limits

  • Cannot draw: hold Ctrl, or enable left-click drawing. Ensure the pointer is over the canvas, not a panel.
  • Eraser does not work: hold Shift and check eraser width in Quick Pen.
  • Wrong frame cleared: try Ctrl+Z immediately. Clear Page and Delete Frame are different actions.
  • Onion is too cluttered: reduce frame counts and opacity; set future-frame count to zero.
  • Playback is slow: limit the range and use 25% or 50% preview scale.
  • Image sequence creates many downloads: choose ZIP or folder if your browser supports it.
  • Shortcut does not work: check the Shortcuts dialog; the browser may reserve the key. Assign another shortcut.
  • Settings changed after reopening: export/import settings and shortcuts separately; the project JSON is not the settings backup.
  • Need a full reset: save the project first; the app warns that Factory Reset does not save the open project.
